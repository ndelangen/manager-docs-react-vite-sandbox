# Manager docs

This sandbox is a minimal React + Vite project for `@storybook/experimental-addon-manager-docs`. The article renders in the manager. Each story is its own preview iframe.

<Callout tone="info">
This Callout is a custom component block. It mounts in a shadow root, not in the preview iframe.
</Callout>

## Actions

Click the button. The **actions** panel on this instance records `onClick`.

<SB.Story of={ButtonStories.Primary} panel={['actions']} />

## Play function

This story has a play function that clicks the button when the iframe is ready.

<SB.Story of={ButtonStories.Clicked} panel={['actions', 'interactions']} />

The toolbar on this frame is scoped to this iframe. Switch viewports here without changing the other stories.
